# Toolkit

Набор утилит на Go для работы с файлами.

## Технологии

- Go 1.21

## Утилиты

| Утилита | Описание |
|---------|----------|
| app-upload | Загрузка файлов на сервер |
| app-download | Скачивание файлов с сервера |
| app-json | Работа с JSON |
| app-slug | Генерация slug из строки |
| app-dir | Работа с директориями |

## Запуск

```bash
go run app/main.go
```

## Тесты

```bash
go test ./...
```
